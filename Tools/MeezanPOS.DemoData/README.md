# بيانات تجريبية لمنظومة ميزان

أداة تولّد 30 يوم عمل تجريبية في **قاعدة بيانات منفصلة** عن بياناتك الحقيقية:

```
%LOCALAPPDATA%\MeezanPOS_Demo\Meezan.db
```

البيانات الحقيقية في `%LOCALAPPDATA%\MeezanPOS` لا تُمس إطلاقاً (الأداة ترفض العمل إذا أشار المسار إليها).

## ماذا تحتوي

- 30 يوم عمل تنتهي أمس: أيام الخميس والجمعة وبعض الأيام الأخرى بورديتين (صباحية + مسائية)، وبقية الأيام بوردية واحدة (يوم كامل).
- مبيعات نقدية وإلكترونية موزعة على مصرفين، مصروفات نثرية، مرتجعات وطلبات مجانية بأسماء أشخاص، وعجز/زيادة بسيطة في بعض الورديات.
- 5 موردين بفواتير توريد ودفعات نقدية من اليومية وتحويلات مصرفية.
- 4 عمال بحضور يومي وأجور أسبوعية، ومصروفات عامة (إيجار بتحويل مصرفي، كهرباء، مياه، صيانة، إنترنت).
- تسوية وإقفال للنصف الأول من الفترة مع سحب للمالك، ثم ورديات مرحّلة فردياً، وآخر 4 أيام مسودات للمراجعة.

## بيانات الدخول التجريبية

| المستخدم | الدور | كلمة المرور |
|---|---|---|
| `admin` | مدير عام | `Demo@2026` |
| `manager` | مدير | `Demo@2026` |
| `cashier` | كاشير | `Demo@2026` |

جرّب الدخول بكل دور لترى اختلاف الشاشات المتاحة.

## الاستخدام

```bash
# توليد البيانات (أول مرة)
dotnet run --project Tools/MeezanPOS.DemoData

# إعادة التوليد من الصفر (يحذف القاعدة التجريبية فقط)
dotnet run --project Tools/MeezanPOS.DemoData -- --force

# تشغيل المنظومة على البيانات التجريبية (أغلق المنظومة العادية أولاً)
Tools\run_demo.cmd
```

التوليد ثابت النتائج (بذرة عشوائية ثابتة) لكن التواريخ نسبية لتاريخ اليوم.
