# إضافة Graphify

تمت إضافة أداة **Graphify** إلى نظامك بنجاح بناءً على الرابط: https://github.com/safishamsi/graphify

## كيف تستخدم الإضافة؟
لقد قمت بتثبيت الأداة عالمياً في نظامك وربطها مع Claude Code. يمكنك الآن استخدامها داخل Claude Code في أي مشروع لتوليد رسم بياني للمشروع (Knowledge Graph):
```bash
/graphify .
```

## ماذا توفر لك هذه الإضافة؟
1. **خرائط معرفية تفاعلية:** تحويل الكود، مخططات SQL، المستندات، والصور إلى Knowledge Graph تفاعلي وحفظه في `graphify-out/graph.html`.
2. **تحليل ذكي:** توليد تقرير شامل (`GRAPH_REPORT.md`) يوضح العلاقات المهمة، الثغرات، والأسئلة المقترحة.
3. **التكامل مع Obsidian وWiki:** تصدير الرسم البياني لفتحه كخزنة Obsidian أو مقالات Wiki للبحث السريع.
4. **توفير التوكنز:** توفير في استهلاك التوكنز بنسبة تصل إلى 71.5x مقارنة بقراءة الملفات الخام في كل مرة.
