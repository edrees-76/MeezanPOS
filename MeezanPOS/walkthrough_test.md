## 1. إصلاح المصادقة والصلاحيات (Group 1 & 2 & 6)
- **المشكلة:** قاعدة البيانات تحتوي فقط على حساب `admin` محلي، بينما كانت الاختبارات تفحص الدخول بـ `edreeselhery@gmail.com` مما تسبب في فشل تسجيل الدخول وبالتالي فشل التحقق من الصلاحيات.
- **الحل:** تم إدراج مستخدم تجريبي مؤقت في بداية الاختبارات بكلمة مرور مشفرة بـ `BCrypt` ليمثل حساب الـ `Admin` الفعلي، وتم حذفه تلقائياً فور انتهاء الاختبارات.

## 2. إصلاح تعارض المعاملات في SQLite (Group 5 - الخزينة)
- **المشكلة:** عند تنفيذ عملية سحب أو عكس حركة (`ReverseMovementAsync`)، كانت العملية تفشل بسبب استدعاء `BEGIN IMMEDIATE` يدوي على مستوى SQL مع محاولة EF Core لبدء معاملة (`Transaction`) داخلية مما يؤدي لظهور الخطأ:
  `SQLite Error 1: 'cannot start a transaction within a transaction'`
- **الحل:** تم تحديث ملف `CashLedgerService.cs` بالكامل لاستخدام نظام المعاملات الافتراضي لـ EF Core (`BeginTransactionAsync` و `CommitAsync` و `RollbackAsync`) بدلاً من أوامر SQL الخام. هذا ضمن التوافق الكامل مع EF Core و SQLite ومنع تعارض المعاملات.

## 5. مسار ملف قاعدة البيانات
- يتم إنشاء ملف قاعدة البيانات SQLite وتخزينه في المسار التالي على نظام ويندوز:
  `%LOCALAPPDATA%\MeezanPOS\Meezan.db`
  والذي يترجم فعلياً إلى المجلد الخاص بالمستخدم الحالي:
  `C:\Users\DELL\AppData\Local\MeezanPOS\Meezan.db`

- **نعم، هذا هو المكان الصحيح تماماً.** ملف `Meezan` الظاهر في الصورة بنوع (Data Base File) هو قاعدة البيانات النشطة للتطبيق.
- الملف `Meezan_pre_refactor_20260529_023006` هو نسخة احتياطية قديمة تم إنشاؤها تلقائياً قبل إعادة الهيكلة السابقة لضمان أمان البيانات.

- **نعم، يمكنك بالتأكيد حذف ملف `Meezan` (قاعدة البيانات) لبدء تجربة المنظومة من الصفر.**
- عند تشغيل التطبيق بعد حذف الملف، سيقوم محرك EF Core تلقائياً بإنشاء ملف قاعدة بيانات جديد فارغ تماماً وتطبيق جميع جداول النظام من البداية.
- حساب الدخول الافتراضي بعد إعادة الإنشاء سيكون:
  - اسم المستخدم: `admin`
  - كلمة المرور: `admin`

### خطوات حذف قاعدة البيانات وتصفير المنظومة:
1. **إغلاق التطبيق:** تأكد من إغلاق تطبيق MeezanPOS تماماً لكي لا تكون قاعدة البيانات قيد الاستخدام أو مقفلة.
2. **تحديد الملف:** في نافذة متصفح الملفات المفتوحة أمامك حالياً (في المسار `AppData\Local\MeezanPOS`)، ابحث عن الملف المسمى `Meezan` والذي يكون نوعه `Data Base File`.
3. **الحذف:** انقر بالزر الأيمن للفأرة على الملف واختر **Delete (حذف)**، أو حدده واضغط على زر `Delete` في لوحة المفاتيح.
4. **التشغيل:** شغّل التطبيق من جديد، وسيقوم النظام فوراً ببناء قاعدة البيانات من الصفر تلقائياً وتجهيزها.
